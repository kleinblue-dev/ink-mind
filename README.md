# 墨心（ink-mind）

单文件水墨小游戏：三张纸，随便落墨，玩完给你一张「原始信号卡」。
浏览器直接开，手机也能玩。**数据不联网** —— 全部计算都在你自己的设备上完成，不上传任何东西。

本仓只放可运行的那一个 `index.html`（开发过程、验证工具不在这里）。

- 直接玩：<https://kleinblue-dev.github.io/ink-mind/>
- 页面里没有任何外部请求；断网也能玩（前提是页面已经打开过或存了下来）

图案线稿整理自《芥子园画传》白描页的图像素材（画作系清代刻本，本身属公有领域；
带他方水印的素材均未采用）。本仓仅供试用交流、非商用，未附开源许可证（保留权利）。
